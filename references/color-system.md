# 色彩系统 · Color System

> 以核心品牌蓝为主轴的完整色彩架构，兼顾功能逻辑与情感张力，通过精准的色彩分工引导视觉焦点、厘清层级，确保全媒介的品牌一致性。

官方色板共 **15 色**，以下色值为官方原值。**色名与角色分工为本 Skill 基于官方色值推导的工作版本**，非官方逐字命名。

## 对比度实测（WCAG 2.1）

色值好看不等于可读。以下为实测值，**用于判断可读性边界，不作为替换品牌色的理由**——品牌色按官方色值使用，不因对比度而改动。

**门槛**：普通文字 **4.5:1**；大字 **3:1**，而大字指 **18pt（24px）**，或 **14pt 粗体（18.66px，字重 700）**。

| 组合 | 对比度 | 结论 |
| --- | --- | --- |
| `#121212` on `#FFFFFF` | 18.73:1 | AAA — 浅底正文首选 |
| `#002F5B` on `#FFFFFF` | 13.48:1 | AAA — 白底高对比文字 |
| `#707070` on `#FFFFFF` | 4.95:1 | AA — 浅底次级文字 |
| `#121212` on `#007CFF` | 4.75:1 | **AA — 品牌蓝实底上的文字，任何字号都合规** |
| `#707070` on `#121212` | 3.78:1 | 仅大字 — 深底偏弱 |
| `#707070` on `#2F2F2E` | 2.71:1 | **不可用于深底文字** |
| `#C3C3C3` on `#121212` | 10.63:1 | **AAA — 深底次级文字/轴标签的正确色** |
| `#007CFF` on `#FFFFFF` | 3.94:1 | 仅达大字门槛，**不满足普通字号 AA** |
| `#FFFFFF` on `#007CFF` | 3.94:1 | 同上 |
| `#8D9390` on `#FFFFFF` | 3.13:1 | 大字 / 非文本元素 |
| `#00F6FF` on `#FFFFFF` | 1.34:1 | **不可见 — 青色是深底专用** |
| `#00F6FF` on `#121212` | 13.94:1 | AAA — 深底强调 |
| `#C3C3C3` on `#FFFFFF` | 1.76:1 | **仅装饰 — 浅底不得承载文字** |
| 点缀四色 on `#121212` | 12.2–16.9:1 | AAA — 深底强调安全 |

### 用色立场

**品牌色不替换。** `#007CFF` 就是 Kimi 的品牌蓝，用于链接、按钮、强调一律直接使用，不因 3.94:1 而换成 `#002F5B`。

但 3.94:1 **只满足大字门槛，不满足普通字号**。所以真正的约束是**搭配与字号**，不是改色：

| 场景 | 正确做法 |
| --- | --- |
| 品牌蓝实底 + 文字 | 用 `#121212` 深色文字（4.75:1，**任何字号都合规**）——这是默认方案 |
| 品牌蓝实底 + 白字 | 仅当 ≥24px，或 ≥18.66px 且字重 700 |
| 品牌蓝实底 + 小字 | 不要用白字；改用深色文字，或放大字号 |
| 浅底正文 / 次级文字 | `#121212` / `#707070` |
| 深底次级文字 / 轴标签 | `#C3C3C3`（10.63:1）。**不要**用 `#707070`（仅 3.78:1） |
| 图表焦点色 | 浅底用 `#002F5B`，深底用 `#00F6FF` |

### 关于 `#C3C3C3`（易被误读的规则）

**规则是"浅底不得承载文字"，不是"永不使用"。** 该色在墨黑底上是 10.63:1，正是深色主题的次级文字与图表轴标签色；只在白底（1.76:1）才是纯装饰。CSS 中 `--kimi-text-secondary` 随主题切换，正是这个原因。

## 分工原则

```
视觉焦点  →  #007CFF / #00F6FF   （少量、精准）
结构秩序  →  #121212 #707070 #C3C3C3 #E1E3E6 （大量、成体系）
情感温度  →  点缀四色           （克制、单一场景 ≤2 个）
```

关键不是"用哪些颜色"，而是**分工是否清晰**。一页里若三种职责各占一层，层级自然浮现；若混用全部 15 色，则无层级可言。

## 深浅底搭配速查

- **浅色底**：`#FFFFFF` / `#E1E3E6` → 文字 `#121212`，次级 `#707070`，强调 `#007CFF`
- **深色底**：`#121212` → 文字 `#FFFFFF`，次级 `#C3C3C3`（**不是** `#707070`），强调 `#00F6FF` 或 `#A0DAF7`
- **品牌蓝实底**：`#007CFF` → 文字默认用 `#121212`（4.75:1）；需白字时字号 ≥24px 或 ≥18.66px/700

## 代码示例

```css
/* 浅色底 */
.kimi-surface      { background: #FFFFFF; color: #121212; }
.kimi-surface-sub  { background: #E1E3E6; }
.kimi-accent       { background: #007CFF; color: #121212; } /* 蓝底深字：任何字号 AA */
.kimi-accent-white { background: #007CFF; color: #FFFFFF; } /* 仅限 24px+ 或 18.66px/700 */
.kimi-link         { color: #007CFF; }
.kimi-divider      { border-color: #C3C3C3; }               /* 浅底只画线 */

/* 深色底 */
.kimi-surface-dark { background: #121212; color: #FFFFFF; }
.kimi-accent-dark  { color: #00F6FF; }
.kimi-secondary-dark { color: #C3C3C3; }                  /* 深底可承载文字 */
```

机器可读全量 token 见 `../assets/kimi-brand-tokens.json`，可直接引入的 CSS 变量见 `../assets/kimi-brand-theme.css`。
