# 数据可视化 · Data Visualization

> 以清晰、精准且富有目的性的系统化框架，呈现复杂数据。

## 不可违反的原则

> 数据可视化应遵循极简与克制的原则。最重要的是，数据可视化必须准确传达数据，**绝不可造成误导或扭曲**。

具体到执行层面，以下行为一律禁止：

- ❌ 截断坐标轴使差异被放大（Y 轴不从 0 起且未明确标注截断）
- ❌ 3D 柱状图、透视面积图、双 Y 轴制造视觉错觉
- ❌ 饼图超过 5 个扇区，或用面积/角度误导量级关系
- ❌ 未标注单位的数字、未标注样本量的百分比
- ❌ 用红绿对立表达"好/坏"（对色觉障碍用户不友好）
- ❌ 平滑曲线插值制造不存在的趋势拐点

## 官方视觉方向

- **中性灰为底色**，通过**精准的电光蓝高亮**，引导用户关注 Kimi 的核心指标。
- 专为**基准测试与复杂技术指标**打造的数据可视化规范——即：允许高信息密度，但每个元素都必须承载信息。

## 配色映射

```jsonc
{
  "chartSurface":   "#FFFFFF",  // 浅底画布
  "chartSurfaceAlt":"#E1E3E6",  // 交替行 / 次级区块
  "gridLine":        "#C3C3C3",  // 网格线（浅底只画线，不承载文字）
  "axisLabel":       "#707070",  // 坐标轴标签（浅底 4.95:1，AA）
  "axisLine":        "#8D9390",
  "textPrimary":     "#121212",
  "seriesPrimary":   "#007CFF",  // 核心指标
  "seriesFocus":     "#002F5B",  // 焦点 — 深蓝，非青色（青色在白底仅 1.34:1）
  "seriesDeep":      "#00A1FF",
  "seriesNeutral":   "#8D9390",  // 对照/背景系列
  "seriesAlt1":      "#A0DAF7",
  "seriesAlt2":      "#DFC8F5",
  "seriesPositive":  "#B3F4A8",
  "seriesWarning":   "#F4F9A7"
}
```

**深色画布**（终端 / 品牌影片场景）必须整套切换，不能只改画布色：

```jsonc
{
  "chartSurface":   "#121212",
  "chartSurfaceAlt":"#2F2F2E",
  "gridLine":        "#2F2F2E",
  "axisLabel":       "#C3C3C3",  // 深底次级文字的正确色（10.63:1）
  "axisLine":        "#C3C3C3",
  "textPrimary":     "#FFFFFF",
  "seriesPrimary":   "#007CFF",
  "seriesFocus":     "#00F6FF",  // 青色在深底 13.94:1，是深底专用焦点色
  "seriesDeep":      "#00A1FF",
  "seriesNeutral":   "#8D9390"
}
```

> ⚠️ 深底不要沿用浅底的 `#707070` 轴标签：在墨黑上只有 3.78:1，在抬升面 `#2F2F2E` 上仅 2.71:1。反过来，青色焦点也不要放到白底图表上（1.34:1，等于看不见）。

## 系列配色原则

1. **一个画面只有一个焦点色**。需要强调的系列用 `#007CFF` 或 `#00F6FF`，其余一律退到中性灰。
2. **系列数 ≤ 5**。超过 5 个系列应改为分面、排序或"其他"归并。
3. **类别色序固定**：蓝 → 深蓝 → 天蓝 → 青 → 灰。同一个类别在任何图表里颜色不变，跨图表形成一致性。青色只出现在深底图表的焦点位。
4. **连续量用单色渐变**（`#E1E3E6 → #A0DAF7 → #007CFF → #002F5B`），不要用彩虹色带。
5. **发散量以中性灰为中点**（`#002F5B ← #E1E3E6 → #007CFF`），保证正负两侧视觉权重对称。
6. **浅底与深底是两套配色**，画布、网格、轴标签、焦点色要成套切换，不要只改画布色。

## 标注规范

- **数值直接标在图元上**，不要强迫读者在图与轴之间来回跳视。
- 单位写在轴标题或数值后（`18.7 t/s`），不要只标一个裸数字。
- 指标口径必须可查：模型版本、测试集、日期、样本量。
- 基准测试图必须注明对比对象与版本，否则不予采用。

## 字体

- 刻度与标注：`Inter`（400/500）
- 指标数值、模型名、版本号：`Geist Mono`（500）——等宽保证数字纵向对齐
- 数字建议 `font-variant-numeric: tabular-nums`

## 反模式速查

| 反模式 | 正确做法 |
| --- | --- |
| 12 种颜色区分系列 | ≤5 系列，其余归并；或改用排序条形图 |
| 网格线比数据更抢眼 | 网格线降到 `#E1E3E6`–`#C3C3C3`，不加粗 |
| 渐变填充柱状图 | 纯色柱；仅在强调单根时用高亮色 |
| 3D 饼图 / 3D 柱状图 | 平面二维；饼图 ≤5 扇区 |
| 仪表盘堆满卡片 | 一个画面一个焦点问题，其余下沉为次级信息 |
| 双 Y 轴制造相关性 | 拆成上下两张共享 X 轴的图 |
| 动画炫技 | 仅保留必要的入场过渡；数据本身不动画 |
