# 品牌视觉资产与 UI · Brand Visual Assets & UI

## 界面升级

> 界面升级：让每一次打开，都像见到一位老朋友。

UI 被当作**对话的自然延伸**来设计：首页褪去冷峻灰蓝，换上柔和暖白；IP 在中央眨眼，动态图标随指针轻轻跳动；移动端玻璃质感与系统美学无缝融合。轻盈灵动的细节，让每一刻都像一场真实对话，自然展开。

工程含义：

- 暖白优先于纯冷灰蓝的科技底
- 动效是"呼吸"级的（细微、跟随交互），不是弹跳夸张的
- 层次靠柔和阴影与轻微透明（玻璃质感），不靠硬边框堆叠

### 产品侧设计语言

| 主题 | 要点 |
| --- | --- |
| 导航触手可及 | 侧边栏全展开、历史不折叠、关键项置顶、项目归属清晰 |
| 主动执行，实时呈现 | 定时任务、组件、看板；状态可见而非静默 |
| 个性化 | 亲密度累积、技能沉淀、成长日志——长期陪伴感 |
| 随对话流动的 UI | 暖白底 + 中心 IP + 指针驱动的微动效 + 移动端玻璃质感 |

## 生成式视觉资产系统

> 基于生成式算法，Kimi 视觉资产生成器将复杂数据与动态提示词转化为独特的视觉质感——赋予每一个品牌触点统一的 De-coding（解码）质感，同时为创意探索保留无限空间。

<https://www.kimi.com/lp/wallpapers>

把抽象灵感转化为生成式艺术——融合品牌经典色彩与动态质感。需要壁纸、封面、背景板时**优先用官方生成器**，而不是自己拼贴品牌色。

### 有机数字纹理

> 将有机的自然肌理转化为数字像素阵列——连接自然秩序与算法精度。

从网页界面到终端工作空间，这些**经过降噪提炼**的肌理构筑出静谧、沉浸的画布背景——让高性能科技落地于富有触感与人文温度的现实场景。

纹理使用规则：

- ✅ 作为背景层，压在内容之下，透明度可控
- ✅ 低频、细腻、不重复纹理；一个画面只用一种
- ✅ 深底（`#121212`）上最出效果，点缀色微弱发光
- ❌ 不用作前景内容区背景（干扰阅读）
- ❌ 不叠加故障风、扫描线、高饱和噪点

## 品牌触点（实体）

> 从办公环境到品牌物料，我们的物理触点始终保持严谨的结构性、极简的美学，以及持久的品质感。

印刷与物料沿用同一套逻辑：结构严谨（严格对齐与网格）、美学极简（留白充足）、品质持久（材质与印刷精度）。转化到设计文件时，用大留白 + 单一焦点 + 严格对齐即可还原这种观感。

## 品牌影片与影调

> 一种植根于科学好奇心、立足于人文价值的视觉语言。

> 大模型真正吸引人的，不局限于它已经知道什么，还有它面对未知时的态度：好奇、先锋、持续探索，也始终相信还有更好的答案。

影像取向：科学好奇心 + 人文价值。品牌影片的收束句是"想到 Kimi 时，想到的不只是一个模型，也是一种持续建造的力量"——做任何 Kimi 相关影像时，保持"持续建造"的动态感，不要拍成静态的科技展示。

### 影像类内容分类

| 类型 | 要点 |
| --- | --- |
| 产品特性 | 清晰、精准地演示能力与界面 |
| 概念视频 | 前瞻、高品牌调性，传达核心理念 |
| 教程视频 | 呈现从灵感到创意的完整落地流程 |
| 用户故事 | 真实日常，捕捉真实工作生活场景中的温度 |
