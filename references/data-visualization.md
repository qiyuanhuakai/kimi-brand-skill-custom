# 数据可视化 · Data Visualization

> 以清晰、精准且富有目的性的系统化框架，呈现复杂数据。

## 不可违反的原则

> 数据可视化应遵循极简与克制的原则。最重要的是，数据可视化必须准确传达数据，**绝不可造成误导或扭曲**。

具体到执行层面，以下行为一律禁止：

- ❌ 截断坐标轴使差异被放大（Y 轴不从 0 起且未明确标注截断）
- ❌ 3D 柱状图、透视面积图、双 Y 轴制造视觉错觉
- ❌ 饼图超过 5 个扇区，或用面积/角度误导量级关系
- ❌ 未标注单位的数字、未标注样本量的百分比
- ❌ 用红绿对立表达"好/坏"（对色觉障碍用户不友好）
- ❌ 平滑曲线插值制造不存在的趋势拐点

## 官方视觉方向

- **中性灰为底色**，通过**精准的电光蓝高亮**，引导用户关注 Kimi 的核心指标。
- 专为**基准测试与复杂技术指标**打造的数据可视化规范——即：允许高信息密度，但每个元素都必须承载信息。

## 配色映射

```jsonc
// 浅色画布：可用系列仅 4 个
{
  "chartSurface":   "#FFFFFF",
  "chartSurfaceAlt":"#E1E3E6",
  "gridLine":        "#C3C3C3",  // 网格线（浅底只画线，不承载文字）
  "axisLabel":       "#121212",  // 浅底轴标签用 ink：白底 18.73:1、浅灰次级画布 14.57:1
  "axisLine":        "#8D9390",
  "textPrimary":     "#121212",
  "series": {
    "1": "#002F5B",   // 13.48 / 10.48
    "2": "#007CFF",   //  3.94 /  3.07
    "3": "#707070",   //  4.95 /  3.85
    "4": "#121212"    // 18.73 / 14.57
  }
}
```

**深色画布**（终端 / 品牌影片场景）必须整套切换，不能只改画布色：

```jsonc
// 深色画布：可用系列 5 个
{
  "chartSurface":   "#121212",
  "chartSurfaceAlt":"#2F2F2E",
  "gridLine":        "#2F2F2E",
  "axisLabel":       "#C3C3C3",  // 深底次级文字的正确色（10.63:1）
  "axisLine":        "#C3C3C3",
  "textPrimary":     "#FFFFFF",
  "series": {
    "1": "#00F6FF",   // 13.94 /  9.97
    "2": "#007CFF",   //  4.75 /  3.40
    "3": "#A0DAF7",   // 12.37 /  8.85
    "4": "#8D9390",   //  5.98 /  4.28
    "5": "#C3C3C3"    // 10.63 /  7.60
  }
}
```

> ⚠️ 深底不要沿用浅底的 `#707070` 轴标签：在墨黑上只有 3.78:1，在抬升面 `#2F2F2E` 上仅 2.71:1。反过来，青色焦点也不要放到白底图表上（1.34:1，等于看不见）。
> ⚠️ 浅底轴标签也不能用 `#707070` 放上浅灰次级画布（3.85:1）——所以浅底统一用 ink，在白底与浅灰底都合规。

## 系列配色的硬门槛：非文本对比度 3:1

> 承载数据的线条、柱体、扇区，如果它是**该数值的唯一视觉线索**，就必须对画布达到 **3:1**（WCAG 1.4.11）。这不是文字对比度，是图形对象对比度——低于 3:1 的系列色在真实阅读距离上会"消失"。

按这个门槛实测官方色板，两个主题的结论**不一样**，必须分开说：

| 画布 | 达到 3:1 的官方色数量 | 建议系列数 | 依据 |
| --- | ---: | ---: | --- |
| 浅色（`#FFFFFF` 与 `#E1E3E6` **都要**满足） | **4** / 15 | **≤ 4** | **对比度硬上限**——色板本身只有 4 个色够用 |
| 深色（`#121212` 与 `#2F2F2E` 都要满足） | **12** / 15 | **≤ 5** | **克制与辨识度**——对比度不是瓶颈，5 是设计建议 |

浅色可用色：`#002F5B` 13.48/10.48 · `#007CFF` 3.94/3.07 · `#707070` 4.95/3.85 · `#121212` 18.73/14.57

深色达到 3:1 的 12 色：`#007CFF` `#00A1FF` `#A0DAF7` `#00F6FF` `#DFC8F5` `#FFD1D4` `#B3F4A8` `#F4F9A7` `#8D9390` `#C3C3C3` `#E1E3E6` `#FFFFFF`

> ⚠️ **深底的 5 不是对比度决定的。** 12 个色都过 3:1，背景对比度无法单独决定系列数量上限。5 是**辨识度**上的建议：这 12 色里有若干在墨黑上的亮度极接近——`#A0DAF7` 与 `#DFC8F5` 只差 0.13:1，`#B3F4A8` 与 `#E1E3E6` 只差 0.08:1——同时出现会分不清。**要选的是"能互相区分"的颜色，不只是"能看见"的颜色。** 本 Skill 发布的深底 5 色按在墨黑上的亮度排序，相邻最小间隔 ≥1.0:1。

### 被排除的色（浅底系列位）

| 色 | 白底 | 浅灰画布 | 判定 |
| --- | ---: | ---: | --- |
| `#8D9390` | 3.13 | **2.43** | 仅纯白画布可用，上了浅灰分区就失效 |
| `#00A1FF` | 2.78 | 2.17 | 不可作浅底系列 |
| `#A0DAF7` | 1.51 | 1.18 | 不可作浅底系列 |
| `#00F6FF` | 1.34 | 1.05 | 深底专用 |
| `#C3C3C3` | 1.76 | 1.37 | 只画网格线与边框 |
| 点缀四色 | 1.11–1.53 | ~1.0–1.2 | 不可作浅底系列 |

深底同样有排除项：`#002F5B`（1.39/1.01）在深色上等于隐形；`#121212`、`#707070` 在抬升面 `#2F2F2E` 上只有 1.40/2.71。

### 超过上限怎么办

1. **优先用非颜色编码**：直接标注数值、区分标记形状、拆成小多图。类别多于 4 个时这本来就是更好的做法。
2. **归并**为"其他"，或改成排序条形图。
3. **低对比填充 + 高对比描边**（唯一的颜色豁免）：大面积色块可以低于 3:1，但必须给 1–2px 的合规描边（如 `#002F5B`），由描边承担可辨识的边界。仅适用于形状本身不是唯一线索的大面积区域。

## 系列配色原则

1. **一个画面只有一个焦点色**。需要强调的系列用焦点色（浅底 `#002F5B`，深底 `#00F6FF`），其余退到中性灰阶。
2. **系列数：浅底 ≤ 4（对比度硬上限），深底 ≤ 5（辨识度建议）**。超过按上一节处理，不要靠加颜色硬撑。
3. **类别色序固定**，跨图表一致。浅底与深底的色序不同（见上表），切换主题时按对应表取用。
4. **连续量用单色渐变**（`#E1E3E6 → #A0DAF7 → #007CFF → #002F5B`），不要用彩虹色带。渐变是 3:1 规则的例外：它按连续梯度阅读而非离散系列，每级都需标注；但最浅一级仍需与画布有可见边界。
5. **发散量以中性灰为中点**（`#002F5B ← #E1E3E6 → #007CFF`），保证正负两侧视觉权重对称。
6. **浅底与深底是两套配色**，画布、网格、轴标签、焦点色要成套切换，不要只改画布色。

## 标注规范

- **数值直接标在图元上**，不要强迫读者在图与轴之间来回跳视。
- 单位写在轴标题或数值后（`18.7 t/s`），不要只标一个裸数字。
- 指标口径必须可查：模型版本、测试集、日期、样本量。
- 基准测试图必须注明对比对象与版本，否则不予采用。

## 字体

- 刻度与标注：`Inter`（400/500）
- 指标数值、模型名、版本号：`Geist Mono`（500）——等宽保证数字纵向对齐
- 数字建议 `font-variant-numeric: tabular-nums`

## 反模式速查

| 反模式 | 正确做法 |
| --- | --- |
| 12 种颜色区分系列 | ≤5 系列，其余归并；或改用排序条形图 |
| 网格线比数据更抢眼 | 网格线降到 `#E1E3E6`–`#C3C3C3`，不加粗 |
| 渐变填充柱状图 | 纯色柱；仅在强调单根时用高亮色 |
| 3D 饼图 / 3D 柱状图 | 平面二维；饼图 ≤5 扇区 |
| 仪表盘堆满卡片 | 一个画面一个焦点问题，其余下沉为次级信息 |
| 双 Y 轴制造相关性 | 拆成上下两张共享 X 轴的图 |
| 动画炫技 | 仅保留必要的入场过渡；数据本身不动画 |
