# 色彩系统 · Color System

> 以核心品牌蓝为主轴的完整色彩架构，兼顾功能逻辑与情感张力，通过精准的色彩分工引导视觉焦点、厘清层级，确保全媒介的品牌一致性。

官方色板共 **15 色**，以下色值为官方原值。**色名与角色分工为本 Skill 基于官方色值推导的工作版本**，非官方逐字命名。

## 对比度实测（WCAG 2.1）

色值好看不等于可读。实测结果决定用在哪：

| 组合 | 对比度 | 结论 |
| --- | --- | --- |
| `#121212` on `#FFFFFF` | 18.73:1 | AAA — 正文首选 |
| `#002F5B` on `#FFFFFF` | 13.48:1 | AAA — 白底正文/链接首选 |
| `#707070` on `#FFFFFF` | 4.95:1 | AA — 白底次级文字 |
| `#121212` on `#007CFF` | 4.75:1 | AA — 品牌蓝实底上的深色小字 |
| `#007CFF` on `#FFFFFF` | 3.94:1 | **仅大字** — 不可用于白底小字号正文 |
| `#FFFFFF` on `#007CFF` | 3.94:1 | **仅大字** — 白字按钮需 ≥18.66px 或 ≥14px 粗体 |
| `#8D9390` on `#FFFFFF` | 3.13:1 | 仅大字 / 非文本元素 |
| `#C3C3C3` on `#FFFFFF` | 1.76:1 | **仅装饰** — 不可承载文字 |
| `#E1E3E6` on `#121212` | 14.57:1 | AAA — 深色底主文字 |
| `#A0DAF7` / `#00F6FF` / 点缀四色 on `#121212` | 12.2–16.9:1 | AAA — 深色底强调安全 |

### 由对比度得出的硬规则

- **白底正文链接用 `#002F5B`，不要用 `#007CFF`。** 品牌蓝在白底只有 3.94:1，小字号会不达标。
- **需要 AA 级小字白字按钮时，把底色从 `#007CFF` 加深到 `#002F5B`**（白字对比度 13.48:1）。若坚持用品牌蓝，正文字号必须 ≥18.66px 或 ≥14px 且 700 字重。
- `#C3C3C3` 只能画线、画边框、画骨架，**永远不承载文字**。

## 分工原则

```
视觉焦点  →  #007CFF / #00F6FF   （少量、精准）
结构秩序  →  #121212 #707070 #C3C3C3 #E1E3E6 （大量、成体系）
情感温度  →  点缀四色           （克制、单一场景 ≤2 个）
```

关键不是"用哪些颜色"，而是**分工是否清晰**。一页里若三种职责各占一层，层级自然浮现；若混用全部 15 色，则无层级可言。

## 深浅底搭配速查

- **浅色底**：`#FFFFFF` / `#E1E3E6` → 文字 `#121212`，次级 `#707070`，强调 `#002F5B` 或大字号 `#007CFF`
- **深色底**：`#121212` → 文字 `#FFFFFF`，次级 `#C3C3C3`，强调 `#00F6FF` 或 `#A0DAF7`
- **品牌蓝实底**：`#007CFF` → 文字 `#FFFFFF`（仅大字）；小字场景改用 `#002F5B` 实底

## 代码示例

```css
/* 浅色底 */
.kimi-surface      { background: #FFFFFF; color: #121212; }
.kimi-surface-sub  { background: #E1E3E6; }
.kimi-accent       { background: #007CFF; color: #FFFFFF; }
.kimi-accent-safe  { background: #002F5B; color: #FFFFFF; } /* AA 小字安全 */
.kimi-divider      { border-color: #C3C3C3; }

/* 深色底 */
.kimi-surface-dark { background: #121212; color: #FFFFFF; }
.kimi-accent-dark  { color: #00F6FF; }
```
